Glance  —  鼠标取词翻译          作者：Joshua Hu
========================================================
当前版本：1.0.0

它能做什么 / 优势
----------------
· 全局取词，不挑软件：浏览器、PDF、Word、聊天窗口、图片、视频字幕……
  只要屏幕上看得到就能翻，靠的是截图 + 文字识别，不依赖某个程序的接口。
· 单词和句子一起翻：卡片上半是这个词的音标 + 按词性(n. v. adj.)分组的
  中文释义，下半是它所在整句的翻译，原文和译文里的目标词同色高亮。
· 音标 / 词性离线可用：内置约 24 万常用词词典，没网也能查词看音标；
  只有“整句翻译”才需要联网。
· 不打扰：默认按住 Ctrl 才翻译，松开即消失；想留着看点右上角 📌 钉住。
· 顺手小功能：🔊 朗读、浅色/深色主题、开机自启、翻译来源一键切换。
· 绿色免安装：一个 exe，双击即用，不写注册表，删掉就没了。


怎么开启 / 关闭 / 日常怎么用
--------------------------
【开启】双击 Glance.exe。
        没有主窗口，任务栏右下角托盘区出现一个蓝色“G”图标 = 正在运行。
        （双击不是安装，不进 Program Files、不改系统设置、没有安装向导。）

【关闭】右键托盘“G”图标 → “退出 Glance”。

【日常】开机后双击一次即可，它就一直待在托盘里。
        想每次开机自动启动：右键托盘图标 → 勾选“开机自启”。

【用法】1) 按住键盘 Ctrl 不放；
        2) 鼠标移到任意英文单词上，停顿约 0.15 秒；
        3) 弹出卡片：音标、分词性释义、整句翻译；
        4) 松开 Ctrl，卡片消失；
        想固定住：点卡片右上角 📌（再点一次或点 ✕ 取消），钉住后可拖动；
        点 🔊 朗读单词。


首次运行如果提示“缺少 OCR 语言包”
--------------------------------
设置 → 时间和语言 → 语言和区域 → English → 语言选项
  → 安装“光学字符识别 (OCR)”，然后重新启动 Glance。（一次性）


托盘右键菜单
------------
· 切换为 Google 翻译 / 切换为本地词典   —— 词义来源。本地=离线词典(快、
  有音标词性)；Google=在线翻译的措辞更自然。整句翻译两种都用 Google。
· 切换为浅色界面 / 切换为深色界面        —— 默认深色。
· 朗读单词                               —— 打勾后每次弹出自动朗读。
· 开机自启
· 打开配置文件 / 重新加载配置             —— 改 config.json 后点“重新加载”。
· 退出 Glance
· 最下面一行显示当前版本号和作者。


发给别人用
----------
只需要发 Glance.exe 这一个文件（词典已经打包在里面）。
对方电脑需要 Windows 10/11，并按上面第一次运行的提示装一次英文 OCR 语言包。


常见问题
--------
· 卡片不出现：确认按住的是 Ctrl；确认 OCR 语言包已装；小字识别率低，可在
  config.json 调大 capture_width/height，或提高系统缩放。
· 中文译文里的词没变蓝：机器翻译换了同义词，属正常，英文侧仍会高亮。
· 显示“⚠ …”：翻译接口失败（被墙 / 频率超限），把 config.json 的
  engine_order 改成 ["mymemory"]，或给系统挂代理。
· 杀毒软件报警：PyInstaller 打包的 exe 常被误报，加信任即可。
